DCCFI SPIN THE WHEEL — Quick Setup
====================================

The app works immediately with built-in SVG graphics.
To use YOUR actual photos, place these two files in the
SAME folder as SPINTHEWHEEL.html:

  dccfi-logo.png      ← the DCCFI church logo image
  jesus-cartoon.png   ← the Jesus cartoon image

Then refresh the page — the real images will load automatically.

FEATURES
--------
• Spin the Wheel with 3-second smooth spin
• Jesus cartoon dances while spinning, celebrates on result
• CRUD for participant names:
    - Add  : type name + press Enter or click "+ Add"
    - Edit : click ✏️ icon, change name, click 💾 or press Enter
    - Delete: click 🗑️ icon
• Confetti burst when a winner is selected
• Works fully offline — no internet required (fonts load from Google if online)
